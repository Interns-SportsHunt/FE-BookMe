# Sporty Turf Hub

**Sporty Turf Hub** is a web application that allows users to discover, filter, and book sports turfs with ease. It also provides venue hosts with tools to manage their turfs, view bookings, and track performance in real-time.

This repository (`FE-BookMe`) contains the **frontend** codebase of the application, built using React, TypeScript, Tailwind CSS, and ShadCN UI components.

---

## 🔧 Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- ShadCN UI

---

## 🚀 Getting Started

### Prerequisites

- Node.js and npm  
  We recommend using [nvm](https://github.com/nvm-sh/nvm#installing-and-updating) to manage Node versions.

### Setup Instructions

```sh
# Step 1: Clone the repository
git clone <YOUR_GIT_URL>

# Step 2: Navigate into the project directory
cd FE-BookMe

# Step 3: Install dependencies
npm install

# Step 4: Start the development server
npm run dev
